VSCOPE(1)
=========
:doctype: manpage

NAME
----
vscope - VScope Data Acquisition Software

SYNOPSIS
--------
*vscope*

DESCRIPTION
-----------
The *vscope*(1) command starts the VScope Data Acquisition system.

OPTIONS
-------
None.

BUGS
----
VScope has been used daily in our lab for 15 years now. Some bugs remain.
Please contact the author if one bites you.
